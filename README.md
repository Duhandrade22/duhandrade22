### 🚀 Projetos em destaque

**[Vetly](https://vetly.app.br)**
SaaS de gestão para veterinários autônomos: agendamento, cadastro de tutores e
animais, prontuário eletrônico, geração de prescrição em PDF e dashboard de métricas.

**[Nearby](https://github.com/Duhandrade22/Nearby)**
Aplicação mobile — Busca restaurantes mais proximos e aplica cupons de desconto.

**[Fintech](https://github.com/Duhandrade22/Fintech)**
Dashboard financeiro - Projeto de conclusão de curso da Origamid, construído com React + TypeScript.

**[nlw-esports](https://github.com/Duhandrade22/nlw-esports)**
Aplicação React + TypeScript integrada a uma API em Node.js, para criação de
anúncios e conexão de jogadores em busca de duo/grupo para jogar.
